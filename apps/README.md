# Applications

Application surfaces will live here as they become implementation-ready.

- `desktop/` — Tauri resident desktop application.
- `web/` — account, settings, history, vocabulary, privacy, and product website.
- `android-ime/` — Android Input Method Editor (IME).
- `ios-keyboard/` — iOS/iPadOS custom keyboard extension.

Platform-specific applications should consume the shared contracts from `packages/`.
