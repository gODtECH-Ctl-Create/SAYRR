# V1 Beta Plan

## Beta objective

Prove that users prefer Voice Input Layer over ordinary typing/dictation for real work messages.

## Beta cohort

Start with a small controlled group of Nigerian users who type frequently and use a mix of messaging, work, and browser applications.

## Beta tasks

Each participant should complete:

1. A short WhatsApp/Telegram-style message.
2. A longer work message.
3. A message containing names.
4. A message containing technical vocabulary.
5. A message in Nigerian English.
6. A message with punctuation and paragraph breaks.

## Feedback questions

- Was activation obvious?
- Did speech recognition feel faster than typing?
- Did the cleanup preserve what you meant?
- Did the insertion land in the correct text field?
- Did you trust the product with sensitive messages?
- What did you still have to correct manually?

## Beta exit criteria

The product should not expand into command/action features until the core voice insertion loop is repeatedly successful in real applications.
